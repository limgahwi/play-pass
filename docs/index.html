개인정보처리방침

PlayPass (플레이 패스)

PlayPass는 이용자의 개인정보를 수집하지 않습니다.
회원가입과 로그인이 없으며, 입력하신 정보는 이용자의 기기 안에만 저장되고 운영자의 서버로 전송되지 않습니다.

1. 수집하는 개인정보

없습니다. PlayPass는 회원가입, 로그인, 계정 생성 절차를 두지 않으며, 이용자를 식별할 수 있는 어떠한 정보도 서버로 전송하거나 저장하지 않습니다.

2. 기기 안에 저장되는 정보

서비스 이용을 위해 이용자가 직접 입력한 아래 정보는 이용자 기기의 앱 저장 공간(IndexedDB)에만 보관됩니다. 운영자는 이 정보에 접근할 수 없습니다.

항목용도
선수 이름, 학교, 학년, 반, 소속팀명, 종별, 연락처 대회 제출 서류의 해당 칸을 채우기 위함
보호자 이름, 지도자 이름(선택) 서류의 확인자란을 채우기 위함
전자서명 이미지 서류의 서명란에 표시하기 위함
서류 생성 기록(대회 식별자, 문서 종류, 생성 일시) 이용자가 본인의 이용 내역을 확인하기 위함. 개인 식별 정보를 포함하지 않음

PlayPass는 서류 작성에 실제로 필요한 항목만 받습니다. 생년월일과 주소는 대상 서류의 어느 칸에도 없으므로 입력받지 않습니다.

3. 서버와 주고받는 정보

PlayPass가 서버에서 내려받는 정보는 대회 일정과 서류 양식(PDF)뿐이며, 여기에는 개인정보가 포함되지 않습니다. 이용자가 입력한 정보나 전자서명이 서버로 전송되는 경로는 존재하지 않습니다.

4. 완성된 서류의 처리

작성이 끝난 PDF 파일은 이용자의 기기에서 생성되며, 서버를 거치지 않습니다. 이용자가 직접 선택한 방법(메신저, 이메일, 파일 저장 등)으로만 외부로 나갑니다. 이후의 보관과 전달은 이용자의 관리 아래 있습니다.

5. 백업 파일

이용자는 기기 안의 정보를 백업 파일(.ppbk)로 내보낼 수 있습니다. 이 파일은 이용자가 정한 비밀번호로 AES-256-GCM 방식으로 암호화되며, 비밀번호 없이는 열 수 없습니다.

  • 백업 파일은 이용자의 기기 또는 이용자가 선택한 위치에만 저장됩니다.
  • 운영자는 백업 파일과 비밀번호를 보관하지 않으며, 복구를 도울 수 없습니다.
  • 비밀번호를 분실하면 해당 백업 파일은 복원할 수 없습니다.

6. 알림

대회 마감 알림은 이용자 기기 안에서만 예약되고 표시되는 기기 내 알림입니다. 알림을 위해 기기 식별자나 토큰을 서버로 전송하지 않습니다. 알림 수신 여부는 기기 설정에서 언제든지 변경할 수 있습니다.

7. 제3자 제공 및 처리위탁

수집하는 개인정보가 없으므로 제3자에게 제공하거나 처리를 위탁하는 개인정보도 없습니다. 광고를 게재하지 않으며, 광고 식별자나 분석 도구를 통한 이용자 추적을 하지 않습니다.

8. 아동의 개인정보

PlayPass는 학부모와 지도자가 사용하도록 만들어진 서비스입니다. 선수(아동)의 정보는 보호자 또는 지도자가 직접 입력하며, 해당 정보는 기기 밖으로 전송되지 않고 운영자에게 제공되지 않습니다. 운영자는 아동으로부터 직접 개인정보를 수집하지 않습니다.

9. 보유 기간과 파기

운영자가 보유하는 개인정보가 없으므로 별도의 보유 기간이 존재하지 않습니다. 기기에 저장된 정보는 이용자가 다음 방법으로 언제든지 삭제할 수 있습니다.

  • 앱 내 설정 → 모든 데이터 지우기
  • 앱 삭제(제거)

삭제한 정보는 복구되지 않습니다.

10. 이용자의 권리

기기에 저장된 정보는 이용자가 앱 안에서 직접 열람·수정·삭제할 수 있습니다. 운영자가 보유한 정보가 없으므로 열람·정정·삭제를 운영자에게 요청할 대상이 없습니다.

11. 안전성 확보 조치

  • 개인정보를 서버에 저장하지 않아 서버 유출 위험이 원천적으로 없습니다.
  • 백업 파일은 이용자 비밀번호 기반 암호화(PBKDF2 + AES-256-GCM)로 보호됩니다.
  • 기기 안의 정보는 운영체제가 제공하는 앱별 저장 공간 격리 아래 보관됩니다.
